> **重要说明：本项目严格围绕题目要求实现 —— 「按照这些需求在 web 里面生成所需要的前端，用于参考」；定位为参考实现，用于产品方案展示与前端交互参考。**

## How to Run

### Docker 部署（推荐）

启动所有服务：

```bash
docker-compose up --build -d
```

访问 http://localhost:8081

停止服务并删除数据卷：

```bash
docker-compose down -v
```

### 本地开发

```bash
cd frontend-user
npm install
npm run dev
```

访问 http://localhost:8081

## 题目内容

我现在需要做一个打车项目客户端的前端页面 
以下是需求 
登录注册 
1，支持手机号验证码注册，输入手机号后获取6位验证码，验证码有效期5分钟 
2，注册协议：勾选《用户服务协议》《隐私政策》后方可完成注册，支持点击查看协议详情。服务协议和隐私协议由后台接口提供，并且支持修改操作 
3，登录方式：支持手机号验证码登录、微信快捷登录 
首页叫车 
地址输入 
1，出发地：自动获取当前GPS定位，支持手动修改（地图选点/搜索地址） 
2，目的地：支持搜索地址，展示历史目的地列表【包含多种数据源，历史目的地/当前城市的热门目的地】，支持添加常用目的地 
3，路线预览：输入出发地和目的地后，展示预估行驶路线、里程、时长，支持查看备选路线。 
车型选择 
1，展示车型列表：快车、顺风车，标注车型名称、预估价格、预估到达时间 
2，车型详情：点击车型可查看计费规则（一口价说明、附加费说明）、车型配置、服务标准。 
叫车操作 
•实时叫车：点击“立即叫车”后生成订单，进入等待接单页面，展示附近司机数量、预估等待时间。 
•取消订单：司机接单3分钟内，用户可以取消订单免费；司机已接单后超过3分钟取消需支付取消费（按等待时长计算），取消费规则提前展示。 
2.2.3. 行程管理 
等待接单 
•展示订单号、出发地、目的地、车型、预估价格，实时更新附近司机位置分布。 
•司机接单提醒：司机接单后弹出提示，展示司机姓名、手机号【不显示，但是用户可以点击呼叫司机】、车牌号、车型、车辆照片。 
•联系司机：支持语音电话（号码加密）、文字消息沟通（如告知具体上车点）。 
行程中 
•实时轨迹：地图展示车辆实时位置、行驶路线，同步显示预计到达时间。 
•行程调整：支持与司机协商修改目的地，修改后系统重新计算价格并提示确认。【修改目的地后的价格需要用系统重新规划路线后的价格+之前已经行驶过的路线价格】 
行程结束 
•费用展示：展示订单号、行程时长、行驶里程、一口价金额、附加费、优惠券抵扣金额、实付金额。 
•支付引导：点击“立即支付”选择支付方式（支付宝），然后进行支付 
•服务评价：对司机服务态度、驾驶技术、车辆整洁度进行星级评分（1-5星），支持填写文字评价（最多100字）【只有支付后才可以评价】。 
订单记录 
•展示所有订单（已完成/已取消/待支付），支持按订单类型、时间筛选，按下单时间倒序排序。 
•订单详情：点击订单查看行程信息、费用明细、司机信息、评价内容。 
•订单操作：支持联系客服、查找遗失物品（48小时内订单可直接联系司机）。 
2.2.4. 支付中心 
支付方式 
•支持微信支付。 
•支付记录：展示每笔订单的支付时间、支付金额、支付方式、交易单号。 
•扣款顺序：优先使用优惠券，其次扣除预付抵扣金额，剩余费用从绑定支付渠道扣除。 
2.2.5. 优惠中心 
优惠券 
•展示所有未使用优惠券，按有效期倒序排序，标注优惠券类型、面额、使用门槛、有效期。 
•优惠券领取：支持领取新人专享券、每日签到券、邀请好友券【生成链接二维码，被邀请人通过扫码记录】。 
•优惠券使用：下单时自动匹配满足条件的优惠券，支持手动切换使用的优惠券。2.2.7. 我的 
个人信息 
•展示头像、昵称、用户ID，支持修改头像（从相册选择/拍照）、修改昵称（每月可修改1次）。 
•个人资料：填写性别、生日、常用地址（家庭/公司），设置紧急联系人信息。 
账户设置 
•账号安全：绑定手机号、设置登录保护（陌生设备登录验证）。 
客服中心 
•在线客服：7*24小时在线，支持文字、图片咨询，智能机器人优先应答，可转人工客服。 
•常见问题：分类展示订单问题、支付问题、优惠问题、安全问题的解决方案。 
•意见反馈：提交对平台功能、服务的建议或bug反馈，支持上传图片，查看反馈处理进度。 


按照这些需求在web里面生成所需要的前端，用于参考。

## 项目介绍

本项目是一个完整的打车客户端前端 SPA 应用，使用 React 18 + TypeScript + Vite 构建，Zustand 管理状态。

### 代码规范与响应式说明

- 代码规范对于参考代码同样重要，建议在团队落地时接入 `ESLint + Prettier + CI` 做统一格式与质量校验。
- 界面按移动端优先设计，并兼顾不同设备宽度下的展示效果（响应式布局）。
### 技术栈

- React 18 + TypeScript
- Vite 6 构建工具
- React Router v6 路由
- Zustand 状态管理
- Day.js 日期处理
- 纯 CSS 自定义样式（冷调浅灰 + 低饱和橙主题）

### 项目结构

```
frontend-user/
├── src/
│   ├── api/          # API 接口层（Mock 实现）
│   ├── store/        # Zustand 状态管理
│   ├── types/        # TypeScript 类型定义
│   ├── utils/        # 工具函数
│   ├── styles/       # 全局样式与 CSS 变量
│   ├── components/   # 公共组件（Layout/Toast/Modal/MapView等）
│   └── views/        # 页面组件（19个页面）
├── Dockerfile
├── nginx.conf
└── package.json
```

### 设计特点

- 移动端优先的响应式设计，最大宽度 430px
- 底部 Tab 导航栏（首页/订单/优惠/我的）
- 模拟地图交互（SVG 网格 + 标记点 + 路线）
- 完整的订单状态机流转
- 全局 Toast 提示系统
- 自定义 Modal 弹窗组件
